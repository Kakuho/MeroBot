Basic setup guide for merobot

Throughout the document:

  * MEROBOT_ROOT refers to the root of the source code directory.

  * File locations are wrapped in backticks (`)
      e.g, `MEROBOT_ROOT/file.txt`.

  * Directories are written like File locations but with an ending backslash. 
      e.g, `MEROBOT_ROOT/src/` refers to a directory meanwhile `MEROBOT_ROOT/src/file.txt` refers to file with name
      `file.txt` located in the MEROBOT_ROOT/src/ directory.

  * Terminal commands are wrapped by speechmarks 
      e.g. "docker".

  * The document will tell you whether text in backticks refers to terminal commands or file locations.

  * I refer to a file called "the fat jar". This file can be found on the release page of merobot and is usually called
    something like MeroBot-1.0-SNAPSHOT-jar-with-dependencies.jar.

You can of course deviate from this guide if you know what you're doing. However it's not recommended.

-------------------------------------------------------------------------------------

1) Setup via docker - Linux systems

Docker makes it very easy to setup both merobot, a postgresql database, and a connection from merobot to that database. To setup docker see `https://docs.docker.com/engine/install/` and follow the instructions for your os.

First ensure you have docker installed on your system. Typing "docker" in the terminal should tell you if you have it installed, it should return a list of options on how to use docker (you can ignore these).

Next either download the fat jar from the release page on github or build the fat jar using maven. The fat jar is a file which packages the jvm executable code for merobot together with all the dependencies required.

Place the fat jar in the directory `MEROBOT_ROOT/dist`.

Next set up your .env file. In the project root there is a .env file located at `MEROBOT_ROOT/.env` which contains merobot environmental variables. You may have to write the command "ls -al" in order to see it. You only need to set one of them, the rest can be left alone. See 2) Optional Status Channel for more information about the status channel environmental variable.

To open this the .env file for editing you can use vim by writing "vim .env" in `MEROBOT_ROOT` or any other text editor you like using. 

required fields to set are:
  merobottoken - place your discord bot token here. 

IMPORTANT: DO NOT EVER UPLOAD THIS VALUE ONLINE.

You should now be able to write "docker compose up" in the project root. This runs both merobot and a database which merobot uses to store tracking users and tracking channels. 

You can stop the bot by doing `ctrl+c` which will attempt to gracefully stop merobot.

-------------------------------------------------------------------------------------

2) Optional Status Channel

Merobot has the ability to send update messages if she's going offline or online. To enable this you can set environment variable `status_channel` in the .env file to the id of the channel where you want the updates to be sent to. 

-------------------------------------------------------------------------------------

3) Logging File merobot.log

Merobot logs events both to the command line and a file located in `MEROBOT_ROOT/merobot.log`.

You can periodically delete `merobot.log`, although its useful to keep handy if there's an error since it can provide hint to reproduce the problem.
